Parameters
Model
Ollama model name pulled from ollama list.
Router
How the node picks its next edge: python calls the agent's route(state), llm asks an LLM, blank → static single edge.
Think
Enable the model's chain-of-thought / hidden reasoning channel (Qwen3, gpt-oss, …).
Stream
Stream tokens incrementally rather than wait for the full response.
Temperature
Sampling randomness. 0 = greedy, higher = more creative. Typical 0.2–0.8.
top_p
Nucleus sampling: keep tokens until their cumulative probability ≥ p.
min_p
Drop tokens below this probability (relative to the top token). 0 disables.
Repeat Penalty
Penalty applied to recent tokens to discourage loops. 1.0 = off.
top_k
Cap the candidate set to the k most likely tokens. 0 disables.
num_ctx
Context window in tokens. Higher = more memory but more VRAM.
num_predict
Max tokens to generate. -1 = until the model stops itself.
repeat_last_n
How many recent tokens the repeat penalty looks back at. -1 uses num_ctx.
seed
RNG seed for reproducibility. 0 picks a random one.
