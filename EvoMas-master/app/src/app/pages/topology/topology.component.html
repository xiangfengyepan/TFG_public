Edge types
Unconditional
Always traversed when the source completes — the static graph.add_edge(...) case. state[source] is handed to the target and LangGraph schedules it in the next super-step.
Conditional LLM-routed
Source is an OrchestratorAgent with ≥2 outgoing edges. The LLM emits target name(s); the router whole-word-matches and dispatches only those targets. Falls back to all targets on a parser miss so the run never stalls.
Loop-back / cycle
DFS-detected back-edge (target on the recursion stack). Re-executes the cycle until LangGraph's recursion_limit = max_revisits × num_agents budget is reached.
START / END (virtual)
Connects the virtual START to entry and each end node to virtual END. Edit by dragging from / to the boundary nodes, not by direct manipulation.
Execution model
LangGraph runs the graph in super-steps. A node fires once per super-step, and only after every incoming edge scheduled in the prior super-step has completed — fan-in is a join.
When a node completes, every outgoing edge dispatches in the next super-step in parallel. Fan-out targets run concurrently; the super-step ends only when all of them are done.
