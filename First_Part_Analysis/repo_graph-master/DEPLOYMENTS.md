# Repo-Graph Interactive Deployment URLs

The SWE-bench repository graph is deployed as a fully client-side, interactive
site. The single stable entry point is:

- **Full graph:** <https://xiangfengyepan.github.io/TFG_public/repo-graph/>

The view accepts an optional URL parameter:

- `?repo=<repo_id>` restricts the view to a single repository's subgraph.
